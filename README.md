# 抓抓乐 CLAW ROGUE

像素风抓娃娃机 Roguelite。点一下放下爪子，在币用完前抓够分数；每过一台去小卖部买「爪子配件」，组出自己的流派，闯过 15 台风格各异的娃娃机，最后挑战终极大机。

## 玩法
- **一键操作**：爪子在机台上方左右摆动，点击屏幕（或空格）放下
- **抓取判定**：对准程度 × 爪力 ÷ 奖品重量；重的奖品可能在上升途中滑落
- **得分**：奖品分数 × 倍率；同款抓满 3 只触发「成套」奖励
- **奖品**：小鸭、青蛙、猫咪、兔兔、企鹅、熊熊、星星、金蛋、大熊……还有没用的石头
- **小卖部**：18 种配件（强力弹簧、三指大爪、连抓齿轮、磁吸爪、鸭鸭国王……），最多装 5 个，可半价出售
- **经济**：过关奖励 + 剩余币 + 利息（每 $5 得 $1）
- **15 台机，15 种配色**：糖果粉 → 薄荷汽水 → 奶油布丁 → 晴空云朵 → 樱花物语 → 深海蓝 → 森林抹茶 → 夕阳橘 → 薰衣草 → 雪夜 → 复古街机 → 樱桃红 → 黄金夜 → 星空 → 终极彩虹，每台有独立的机身、玻璃背景图案和灯泡配色
- **难度曲线**：目标分 14 → 20 → 27 → 34 → 42 → 48 → 54 → 60 → 67 → 78 → 84 → 90 → 97 → 104 → 118；每台 7 枚币，第 6 台起 8 枚
- **BOSS 机**：第 5、10 台随机（松爪机、狂摇机、吞币机、石头山），第 15 台是终极大机（爪力 -1，但藏了 3 件稀有奖品）；通关第 15 台即为全部通关
- **失败后**：不会回到第 1 台 —— 可花 $(2 + 台数) 读档重来（保留全部配件），或免费清空配件再挑战当前这台，也可以选择从头开始
- **自动存档**：每次放爪、通关、在小卖部买卖都会存档；关掉页面后回到菜单点「继续」即可接着玩

纯 HTML + Canvas，单个文件，无依赖；所有像素美术由代码实时生成，芯片音乐由 Web Audio 合成。iPhone Safari 竖屏直接玩。

在线游玩：https://wilsonmah.github.io/claw-rogue/
